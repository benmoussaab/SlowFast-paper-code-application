# SlowFast-paper-code-application

This repository contains an implementation and application of the **SlowFast** video recognition model based on the paper:

> *SlowFast Networks for Video Recognition* (Feichtenhofer et al.)

The goal of this project is to experiment with the SlowFast architecture and evaluate its performance on the **UCF101** action recognition dataset.

---

## 📌 Project Description

- Implemented and tested the SlowFast network for video action recognition.
- Used the a subset of **UCF101** dataset for training and evaluation.
- The project focuses on understanding:
  - The dual-pathway architecture (Slow pathway + Fast pathway)
  - Temporal modeling in videos
  - Performance on standard action recognition benchmarks

---

## 📂 Dataset

- **UCF101**: A widely used action recognition dataset with 101 action classes.
- Dataset contains realistic action videos collected from YouTube.
- I used a small subset of it.
Make sure you download UCF101 and organize it in the expected folder structure before training/testing.

---

## ⚙️ Features

- SlowFast model implementation
- Training on UCF101
- Evaluation and testing
- Support for video-based action recognition experiments
